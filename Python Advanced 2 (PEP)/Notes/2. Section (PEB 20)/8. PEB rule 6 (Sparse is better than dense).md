if you can make so that single intention is done one per line, then its better than having everything chained as oneliner. 
- Its harder to debug
- its harder to read
- its... annoying to look at on smaller screens

wrong:
```python
x = 1

if x == 1 : print("Hello, World!")
```

right:
```python
x = 1  
if x == 1:  
	print("Hello, World!")
	
```
