Using the `global` keyword before a global variable inside the function is a mechanism that allows you to alter that variable, even though it resides in a different scope (bad practice).

good:
```python
from instruments import guitars  

guitars.fender(page)  
guitars.ibanez(vai)
```

bad:
```python
from instruments.guitars import fender, ibanez  

fender(page)  
ibanez(vai)
```
With such importing conventions we can see that the fender and ibanez both belong to the quitars subgroup, some coders may not know from the second example that we are instantiating quitars.
