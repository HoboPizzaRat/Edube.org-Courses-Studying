
To get to know the basic commands of pip you can list them with:
```shell
pip help
```

To get more information about specific pip command you can do:
```shell
pip help install
```

To know what packages are already installed in the system you can do:
```shell
pip list
```

Installing dependency can be done by
```shell
pip install pygame
```

If you're not an admin, or you don't want to fatten up your OS by installing pygame system-wide, you can install it for you only:
```shell
pip install --user pygame
```

To install specific version of module you can do the following
```shell
pip install pygame==1.9.2
```


If any of the currently installed packages are **no longer needed** and you want to get rid of them, _pip_ will be useful, too. Its `uninstall` command will execute all the needed steps.

The required syntax is clear and simple:
```shell
pip uninstall package_name
```
