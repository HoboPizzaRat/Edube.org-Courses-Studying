`r` open mode: read
- its only permissions is to read the file duh
- the file associated with the stream **must exist** and has to be readable, otherwise the `open()` function raises an exception.

`w` open mode: write
- its only meant to be used to writing to a file
- the file associated with the stream **doesn't need to exist**; it will be created if it doesnt

`a` open mode: append
- it only appends to a existing file, but with write permissions
- the file associated with the stream doesn't need to exist, it will be created if not

`r+` open mode: read and update
- both read and write operations are allowed for the stream.

`w+` open mode: write and update
- both read and write operations are allowed for the stream.

## the binary stream modes
If there is a letter `b` at the end of the mode string it means that the stream is to be opened in the **binary mode**.

If the mode string ends with a letter `t` the stream is opened in the **text mode**.
- the t mode is the default if not specified
