We're going to show you some basic techniques you can utilize to **read the file contents** in order to process them.


The following snippet opens the file and prints all the contents into screen without buffering or anythign more special

```python
# Opening tzop.txt in read mode, returning it as a file object:
stream = open("tzop.txt", "rt", encoding = "utf-8")

print(stream.read()) # printing the content of the file
```



we can process files more cleanly with the following example
```python
from os import strerror

try:
    cnt = 0
    s = open('text.txt', "rt")
    ch = s.read(1)
    while ch != '':
        print(ch, end='')
        cnt += 1
        ch = s.read(1)
    s.close()
    print("\n\nCharacters in file:", cnt)
except IOError as e:
    print("I/O error occurred: ", strerror(e.errno))
```
where:
- we can read only one character at a time, by specifying read with argument that specifies only reading one character at a time.
- we keep reading one character at a time and increasing the counter as long as until we end up finding an empty character(meaning the file ended)



here is another example that allows iterating content more english like

```python
from os import strerror

try:
    cnt = 0
    s = open('text.txt', "rt")
    content = s.read()
    for ch in content:
        print(ch, end='')
        cnt += 1
    s.close()
    print("\n\nCharacters in file:", cnt)
except IOError as e:
    print("I/O error occurred: ", strerr(e.errno))

```
