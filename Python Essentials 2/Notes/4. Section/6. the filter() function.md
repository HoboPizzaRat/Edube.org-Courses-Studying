```python
from random import seed, randint

seed()
data = [randint(-10,10) for x in range(5)]
filtered = list(filter(lambda x: x > 0 and x % 2 == 0, data))

print(data)
print(filtered)

```

with filter functin you can filter data from other lists and possibly maybe even from iterators im not so sure. 

Anyway the filter function takes 2 arguments
- the function that works as a boolean returning filter(true values stays, false values gets removed)
- the second field is the field that takes the list as an input
