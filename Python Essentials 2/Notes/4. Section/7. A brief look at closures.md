**closure is a technique which allows the storing of values in spite of the fact that the context in which they have been created does not exist anymore**.

There is a brand new element in it – a function (named `inner`) inside another function (named `outer`).

```python
def outer(par):
    loc = par

    def inner():
        return loc
    return inner


var = 1
fun = outer(var)
print(fun())
```



Here is a closure with a function that can affect the closured context that it stores.

```python
def make_closure(par):
    loc = par

    def power(p):
        return p ** loc
    return power


fsqr = make_closure(2)
fcub = make_closure(3)

for i in range(5):
    print(i, fsqr(i), fcub(i))

```
