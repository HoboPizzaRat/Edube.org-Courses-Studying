**Amorphous data is data which have no specific shape or form** - they are just a series of bytes.
- This doesn't mean that these bytes cannot have their own meaning, or cannot represent any useful object, e.g., bitmap graphics.
- Amorphous data cannot be stored using any of the previously presented means - they are neither strings nor lists.

one example of python being able to store amorphous data is the bytearray class

If you want such container you can do:
`data = bytearray(10)`

**you mustn't set any byte array elements with a value which is not an integer** (violating this rule will cause a TypeError exception) and you're **not allowed to assign a value that doesn't come from the range 0 to 255 inclusive**
