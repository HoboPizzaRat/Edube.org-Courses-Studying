```python
from datetime import date

today = date.today()

print("Today:", today)
print("Year:", today.year)
print("Month:", today.month)
print("Day:", today.day)

# this will print:

# Today: 2026-08-18
# Year: 2026
# Month: 8
# Day: 18
```

# Creating a date object from a timestamp

we can get the exact second as an integer format using time.time()
function that needs to be imported with time module

```python
from datetime import date
import time

timestamp = time.time()
print("Timestamp:", timestamp)

d = date.fromtimestamp(timestamp)
print("Date:", d)


```
