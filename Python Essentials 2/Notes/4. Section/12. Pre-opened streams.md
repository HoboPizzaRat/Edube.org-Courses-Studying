We said earlier that any stream operation must be preceded by the `open()` function invocation. There are three well-defined exceptions to the rule.

first we must import these three streams by importing sys
`import sys`

`sys.stdin`
- stdin stream is usually meant for input devices like keyboard and mouse
	- for example the input() function reads data from stdin

`sys.stdout`
- stdout is the standard output stream for system. Usually meant for the basic console output the programs usually have(for example print() function writes to this)

`sys.stderr`
- we haven't presented any method to send the data to this stream (we will do it soon, we promise)
- gives the possibility of redirecting these two types of information to the different targets
	- for example log files etc, possbly im not sure
