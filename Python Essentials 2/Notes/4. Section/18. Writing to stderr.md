```python
from os import strerror

try:
    fo = open('newtext.txt', 'wt')
    for i in range(10):
        fo.write("line #" + str(i+1) + "\n")
    fo.close()
except IOError as e:
    print("I/O error occurred: ", strerror(e.errno))
```

if you want to write to the stderr stream dont try to open it explicitly, just send it as given on the code

if you want to make it distinguished from the normal program flow you can do
```python
import sys
sys.stderr.write("Error message")

```
