**checks if the string contains only digits or alphabetical characters (letters), and returns `True` or `False`** according to the result.

```python
# Demonstrating the isalnum() method:
print('lambda30'.isalnum())
print('lambda'.isalnum())
print('30'.isalnum())
print('@'.isalnum())
print('lambda_30'.isalnum())
print(''.isalnum())

```
