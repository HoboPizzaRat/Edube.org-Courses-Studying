To create basic window in tkinter you must initialize it with the following sequence:
```python
# make tkinter object
skylight = tkinter.Tk()
# setup a tkinter with title
skylight.title("Skylight")

# to run the menu you must invoke mainloop() method
skylight.mainloop()
```

To create a `Button` class object, we make use of its constructor. Its first argument (which is a reference to the target window) is obligatory. All others are optional.

```python
# you must create button, you can specify its text
button = tkinter.Button(skylight, text="Bye!")
# you can setup the buttons placement with place() method
button.place(x=10, y=10)
```
