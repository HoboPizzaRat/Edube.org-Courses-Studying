
The second approach is based on the fact that the serialization is actually done by the method named `default()`, which is a part of the `json.JSONEncoder class`. It gives you the opportunity to overload the method defining a `JSONEncoder's` subclass and to pass it into `dumps()`

The function which is able to **get a JSON string and to turn it into Python data** is named `loads()` – it takes a string (hence the s at the end of its name) and tries to create a Python entity corresponding to the received data.

```python
import json


class Who:
	#initializing the default object

        self.name = name
        self.age = age


# making encoder class which has a fallback to the json.JSONEncoder
class MyEncoder(json.JSONEncoder):
    def default(self, w):
```
