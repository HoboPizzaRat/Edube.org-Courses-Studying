`socket.gaierror` and its name comes from the name of a low-level function (usually provided not by Python but by the OS kernel) named `getaddrinfo()`. The function tries - among others - to find the full address information regarding the received argument.

`socket.timeout`. This exception is raised when the server's reaction doesn't occur in a reasonable time - the length of our patience can be set using a method named `settimeout()`, but we don't want to go into details. We hope you'll forgive us.
