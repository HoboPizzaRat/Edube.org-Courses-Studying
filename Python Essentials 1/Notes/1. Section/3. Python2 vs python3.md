Python 2.7 reached **end-of-life on January 1, 2020**. Use Python 3 for new projects.

## Key Differences

|Feature|Python 2|Python 3|
|---|---|---|
|`print`|`print "hello"`|`print("hello")`|
|Division|`5 / 2 → 2`|`5 / 2 → 2.5`|
|Integer division|`5 / 2`|`5 // 2`|
|Strings|`str` = bytes, `unicode` separate|`str` = Unicode, `bytes` separate|
|`input()`|Evaluates input as Python code ⚠️|Returns a string|
|`raw_input()`|Reads string input|Removed|
|`xrange()`|Lazy range|`range()` is lazy|
|`range()`|Creates a list|Returns a range object|
|`dict.keys()`|Returns list|Returns a view|
|Exceptions|`except E, e:`|`except E as e:`|
|`raise`|`raise E, "msg"`|`raise E("msg")`|
|`<>`|Supported|Removed; use `!=`|
|`long`|Separate integer type|Removed; `int` handles arbitrary precision|
|`basestring`|Exists|Removed|
|`iteritems()`|Exists|Removed; use `.items()`|
|`__future__`|Used for some Python 3 behavior|Usually unnecessary|
