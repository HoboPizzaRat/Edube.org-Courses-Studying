
## or
|Argument `A`|Argument `B`|`A ==or== B`|
|---|---|---|
|`False`|`False`|`False`|
|`False`|`True`|`True`|
|`True`|`False`|`True`|
|`True`|`True`|`True`|
## not
|Argument|`==not==` Argument|
|---|---|
|`False`|`True`|
|`True`|`False`|

## and
|Argument `A`|Argument `B`|`A ==and== B`|
|---|---|---|
|`False`|`False`|`False`|
|`False`|`True`|`False`|
|`True`|`False`|`False`|
|`True`|`True`|`True`|


## using these in the python code


```python
not (p and q) == (not p) or (not q)
  
not (p or q) == (not p) and (not q)
```
