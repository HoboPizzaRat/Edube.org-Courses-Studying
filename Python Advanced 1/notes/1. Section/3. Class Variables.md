Class variables are defined within the class construction, so these variables are available before any class instance is created.


```python
class Demo:  
	class_var = 'shared variable'  

print(Demo.class_var)  
print(Demo.__dict__) 
```

this will output
´´´
`shared variable 
{'__module__': '__main__', 'class_var': 'shared variable', '__dict__': , '__weakref__': , '__doc__': None}`
´´´
