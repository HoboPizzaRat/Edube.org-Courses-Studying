You should use the `try: problematic_code except` code block to surround the "problematic" piece of code. In effect, when the exception is raised, execution is not terminated, but the code following the `except` clause will try to handle the problem in an elegant way.

```python
try:  
	print(int('a'))  
except ValueError:  
	print('You tried to do a nasty thing...')
```

Named exceptions are exceptions that Some carry additional information about the exception itself.

The `UnicodeError` exception – raised when a Unicode-related encoding or decoding error occurs. It is a subclass of ValueError.


You can chain multiple exceptions in order of one another. The first matching exception from the top down is the one that gets executed.
